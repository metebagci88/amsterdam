## Yerel doğrulama kanıtı (CI DEĞİL, production DEĞİL)
Gömülü Postgres 16.2 + vault/auth/pgcrypto shim ile: `baseline → up → up(idempotent) → invariants (CDP3C_INVARIANTS_PASS) → tests (CDP3C_TESTS_PASS, T01–T33) → down_soft → downsoft_assert (CDP3C_DOWNSOFT_ASSERT_PASS)` **hepsi geçti**; iki-bağlantı `cdp3c_concurrency.sh` → `CDP3C_CONCURRENCY_PASS`; `secret_scan_selftest.sh` → `SECRET_SCAN_SELFTEST_PASS`; paket secret-scan temiz. (pgcrypto/vault gerçek extension'ları prod/CI'da; yerelde shim.)
